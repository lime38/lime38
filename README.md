# Hi, I'm Hoyeop 👋

I'm building **[JALHANA](https://jalhana.com)** (잘하나) — turning Korea's fragmented local-council records into public knowledge citizens can actually read.

Local councils decide budgets, welfare, and safety for millions of people, but their records are scattered across hundreds of sites in formats nobody reads. JALHANA collects them, restructures them **issue by issue** (not meeting by meeting), and publishes them with one hard rule:

> **Every AI-generated sentence traces back to the original transcript** — document ID + utterance position + verbatim quote. If it can't be traced, it isn't published.

## What's running today(26-10-04)

- 📚 **260,000+ transcripts** collected from **243 local councils**
- 📰 **12,000+ issue briefs** published, **24 councils live**
- 🔗 **8,700+ tracked promises** by officials — each with its follow-up status and source anchor
- 🧭 An editor, not a judge: issues are curated by impact on people's lives, never scored or ranked

## Themes I work on

Source traceability & provenance-first LLM pipelines · large-scale document processing · multi-agent verification (the generator never verifies its own output) · entity/issue threading across years of records
